# molff

Intra-molecular forcefield library: four engines that share the same data-oriented design (64-byte aligned arrays, parameter packing, cached intermediates) but have no interdependency. `surfmol` orchestrates them together; each can be used standalone with raw arrays.

## Modules

- **`uff.rs`** — Universal Force Field implementation. `Uff` owns bonded topology (atom indices, parameters) and force buffers. Key algorithm: **force piece assembly** — forces are computed per-term (angles, dihedrals, inversions) into separate buffers (`fang`, `fdih`, `finv`), then assembled per-atom via a `Buckets` mapping structure (`a2f`). Bonds are NOT mapped to buckets — evaluated directly in the per-atom loop. `hneigh` caches normalized bond vectors + inverse distance (`Quat4d.xyz = direction, .w = 1/|r|`) to avoid repeated normalization in angle/dihedral/inversion kernels. Angle/dihedral/inversion forces use `Vec2d` as complex numbers for efficient cos(nθ)/sin(nθ) via repeated complex multiplication — no trig calls in the inner loop. Force layout: `[dih0..dih3][inv0..inv3][ang0..ang2][bon0..]` with precomputed offsets (`i0dih`, `i0inv`, `i0ang`, `i0bon`). `eval_forces` returns `(Eb, Ea, Ed, Ei)` energy components. **`setup_params(params, types, neighs)`** — fills all four parameter arrays from `.dat` files + UFF formulas; ports FireCore's `assignUFFparams` (`UFFbuilder.h`). **`set_dummy_params(apos)`** — bond-only testing setup (k=100, l0=current geometry, all other params zero); NOT physical — use `setup_params` for real simulations. See [`/doc/topical_audit/uff.md`](/doc/topical_audit/uff.md) for the cross-implementation map and [`/userguide/uff_spff.md`](/userguide/uff_spff.md) for the end-user guide.

- **`raff.rs`** — **RAFF (Rigid-Atom Force Field)**: the multi-variant port-based rigid-atom engine. Replaces explicit angle/dihedral terms with a single port-spring energy: each atom has 1–4 body-frame "ports" rotated by its quaternion, and a harmonic spring between the rotated port tip and the neighbor position drives both translation and rotation. Supports 4 design axes: (1) rotation solver — `OrientMode::Dynamic` (omega+tau+inertia integration, inner-coupled with Jacobi for Projective) or `OrientMode::Adiabatic` (memoryless Wahba/Horn quaternion eigen solve via `solve_rotation_wahba`); (2) dynamics — `step_force_md` (symplectic Euler), `step_inertial_reset` (velocity reset on v·F<0), `step_fire` (FIRE with adaptive dt + `FireState`), `step_position_based` (dispatches to **3 position-based variants** via `PosSolver::{PbdCompliance, Xpbd, Projective}`: PBD-with-compliance, true XPBD with lagged `λ_acc`, Projective Dynamics Jacobi global solve with inner-coupled rotation), `step_proximal` (IMEX stub), `solve_collisions` (Jacobi sphere-sphere); (3) non-bonded — `eval_nonbonded` (LJ+Coulomb, O(N²), 1-2/1-3 exclusion) + **`eval_nonbonded_broad`** (AABB-culled, identical results); (4) GPU — not yet started. Key structs: `RaffTopology` (port geometry, neighbors, bond params, mass, inertia), `RaffState` (pos, vel, quat, omega), `RaffConfig` (dt, damping, orient mode, `pos_solver`, `pd_inertia`, `vel_reset`, heavy-ball `bmix_*`, **`box_cfg`**), `BoxCfg` (harmonic AABB constraint: enabled, min, max, k), `NbConfig` (non-bonded params), `PosSolver` (position-based variant selector), `FireState` (adaptive dt/alpha for FIRE, `Default` impl). **`eval_box_forces`**: harmonic restoring force `F = k·(limit - x)` for atoms outside the AABB, added to force array for force-based solvers; applied as post-solve position correction `δx = k·(limit-x)·dt²/m` for position-based solvers. Per-port stiffness `k_p = K_bond / 2` (each bond counted twice). Port tip: `tip = x_i + quat_rotate(q_i, port_local · l0)`. `kabsch_rmsd` for geometry comparison (translation/rotation-invariant RMSD). 22 tests in `tests/test_raff.rs` + 9 convergence tests in `tests/test_raff_convergence.rs` + 3 broad-phase parity tests in `tests/test_broad_phase.rs`. **Benchmark binary** `src/bin/raff_bench.rs` — parameter sweep of all solvers, reports n_steps/n_evals/wall-time. See [`/doc/topical_audit/raff.md`](/doc/topical_audit/raff.md) for the full cross-implementation map and [`/notes/tasks/2026-08-28_roadmap_port_based_rigid_ff.md`](/notes/tasks/2026-08-28_roadmap_port_based_rigid_ff.md) for the phased plan.

- **`nonbonded.rs`** — `NonBondedFF`: Lennard-Jones 12-6 + Coulomb + hydrogen bond. Parameters packed as REQH `[R_vdw, sqrt(E_vdw), Q, Hb]` — stores `sqrt(E)` not `E` directly for the geometric-mean combination rule. `make_plqs` precomputes Pauli/London coefficients: `c_l = exp(-α·R)·sqrt(E)`, `c_p = exp(-α·R)·c_l` (exponential damping). Exclusion list: sorted `i32` array of 1-2 and 1-3 neighbor indices (max 16 per atom), traversed in O(n) per atom to skip bonded pairs. PBC support: precomputes all periodic image shift vectors once, iterates over images in `eval_pbc`. Force clamping (`fmax=10.0` eV/Å, enabled by default) prevents numerical explosion at close range. `COULOMB_CONST = 14.3996` eV·Å/e². H-bond term active only when `Hb < 0` (negative flags donor/acceptor). **`BroadPhase`** struct: per-cluster contiguous atom ranges + rebuildable AABB cache + rcut. **`eval_broad()`**: AABB-culled non-bonded eval — only atom pairs whose cluster AABBs overlap (expanded by rcut) are evaluated. Produces identical forces/energy as `eval()` (energy doubled to match `eval`'s double-counted convention). No PBC support yet.

- **`rigid_sp3.rs`** — `RigidSp3FF`: **legacy** single-variant rigid body dynamics for sp³ atoms. Superseded by `raff.rs` which supports all variants. Kept as the `Dynamic+ForceMD` baseline reference. Each atom has 4 local "ports" (bond attachment points) rotated by its quaternion. `set_sp3` sets tetrahedral ports (±1/√3), `set_sp2` trigonal (120° in xy), `set_sp1` linear (±x), `set_point` none. `eval_forces` computes harmonic spring between quaternion-rotated port tip and bonded atom position; accumulates torque `τ = r × F`. Energy factor 0.25 (each bond counted twice). `move_atom_md` integrates both translation (velocity Verlet) and rotation: angular velocity update `ω_new = ω·(1-rot_damp) + τ·I⁻¹·dt`, quaternion update `q_new = normalize(q_ωdt · q_old)`. Moment of inertia approximated as `I = 0.4·⟨l²⟩` (sphere approximation from average bond length).

- **`multigrid.rs`** — **Multigrid V-cycle solver** for linearized molecular elasticity. Solves `A·δx = F` where `A = K + diag(M/Δt²)`. Two operators via the `LinearOp` trait: (1) `TrussOp` — matrix-free bond-only axial-spring stiffness (`K = Σ 2k·n⊗n`), fast and scalable; (2) `UffHessianOp` — full UFF Hessian (bonds + angles + dihedrals + inversions) via central finite differences, capturing aromatic bending/torsion stiffness that bond-only misses. V-cycle: pre-smooth (damped block Jacobi with optional heavy-ball momentum, `jacobi_smooth_momentum`) → restrict residual to coarse space → coarse solve (dense Cholesky via `numcore::cholesky_factor_f64`) → prolongate correction → post-smooth. Coarse basis: **geometric pivots** (`select_pivots_maximin` = BFS farthest-point sampling on bond graph + `build_pivot_prolongation` = inverse-distance interpolation). Galerkin coarse operator `A_c = Pᵀ·A·P`. Also provides `GalerkinLevel` (cached coarse operator + Cholesky for repeated coarse-preconditioned force steps), `ModalQuadratic` (fitted coupled modal elasticity from 2m full-force samples), and `build_bend_twist_modes` (orthonormal out-of-plane bend + axial twist basis for elongated planar molecules). Parity with NumericalMathPlayground `LinarElasticity/`. 7 tests in `tests/test_multigrid.rs` (matvec/diagonal/direct-solve parity, 4.7× convergence on 8×8 grid, cached coarse force parity, fitted modal quadratic parity, bend/twist orthonormality) + 4 molecule benchmarks in `tests/test_multigrid_molecules.rs` (pentacene/hexadecane/DiTriptyceno with bond-only `TrussOp`, pentacene with full UFF `UffHessianOp`). **Key result**: full UFF Hessian has 1000× more out-of-plane bending stiffness than bond-only (7.67 vs 0.007) — inversions + dihedrals provide the physical bending stiffness that axial bonds completely miss at planar equilibrium. MG converges in 2 V-cycles on both operators. See [`/doc/topical_audit/multigrid.md`](/doc/topical_audit/multigrid.md) and [`/notes/reports/2026-08-29_multigrid_consolidated_report.md`](/notes/reports/2026-08-29_multigrid_consolidated_report.md).

## Design decisions

- **Force piece assembly pattern** — term-level forces computed independently, then assembled per-atom via bucket mapping. Enables parallel evaluation of different term types and clean separation of concerns.
- **Cached bond vectors** (`hneigh`) — normalized direction + inverse distance stored per neighbor slot. Angle/dihedral/inversion kernels read from cache instead of recomputing.
- **Complex number angle powers** — `Vec2d` as `(cos θ, sin θ)`, powers via repeated `mul_cmplx`. Avoids `cos(nθ)` trig calls in inner loops.
- **REQH stores sqrt(E)** — geometric mean combination rule `sqrt(Ei·Ej)` becomes `sqrt(Ei)·sqrt(Ej)`, a simple multiply.
- **Sorted exclusion list** — pre-sorted i32 indices enable O(n) skip traversal without hash lookups.
- **64-byte alignment** throughout — SIMD-compatible, cache-line-aligned.
- **RAFF port-spring replaces angle/dihedral** — a single harmonic spring per port replaces the 3-term (angle+dihedral+inversion) UFF machinery. The port tip position encodes both bond length and angle geometry via the quaternion rotation. This is naturally suited to rigid-body dynamics and GPU parallelization (one spring per port, no angle/dihedral traversal).
- **Per-port stiffness halving** — `k_p = K_bond / 2` because each bond contributes two ports (one per atom). Total stiffness of the bond = `k_p_i + k_p_j = K_bond`.
- **Adiabatic rotation = memoryless** — `OrientMode::Adiabatic` re-solves `q_i` every step via Wahba/Horn eigen decomposition of the port covariance matrix. No `omega`, no `tau` integration. More stable than dynamic but does not conserve angular momentum (no rotational inertia).
- **Mass = 1.0 for relaxation** — `RaffTopology::mass[]` defaults to 1.0 (uniform) for all atoms. This is intentional for relaxation: uniform mass gives uniform convergence rate per atom — heavy atoms (C=12, O=16) don't lag behind H=1, so the structure settles in fewer steps. For dynamics (MD with thermal correctness), set physical atomic masses via `set_masses_from_elements()` (planned) and multiply inertia by mass. See [`/notes/designs/raff_theory_equations.md`](/notes/designs/raff_theory_equations.md) §1.3.
- **Port geometry: per-atom ARAP (default) vs per-type** — `set_port_geometry_from_reference(pos)` sets each port to the normalized initial neighbor direction (ARAP — As-Rigid-As-Possible). This is the editor default: identity rotation perfectly aligns all ports at init (E_port=0), and the Wahba solver preserves the original local geometry. `set_port_geometry_from_types(uff_types)` uses idealized sp2/sp3/sp1/point directions from UFF type suffixes — but this is **broken for most molecules** because `build_neighs_from_bonds` assigns ports in bond-list order, not geometric order, making the port-to-neighbor assignment geometrically inconsistent. See [`/notes/designs/raff_theory_equations.md`](/notes/designs/raff_theory_equations.md) §1.4 for the full analysis.
- **Broad-phase AABB culling** — `BroadPhase` holds per-cluster AABBs refitted each step. `eval_broad` / `eval_nonbonded_broad` only evaluate atom pairs whose cluster AABBs overlap (expanded by rcut). Position-only AABBs at fit time, margin at query time (FireCore `NBFF` pattern). Produces identical forces/energy as O(N²) — pure culling optimization. Energy doubled in `eval_broad` to match `eval`'s double-counted convention.

## What does NOT belong here

- Surface interactions → `surfff`
- MD orchestration (combining multiple forcefields) → `surfmol`
- Topology building and parameter files → `moltopo`
- Rendering → `molrender`
- GPU kernels → `oclff` (OpenCL harness for UFF, SPFF, RAFF/RRsp3, GridFF, FAF)
